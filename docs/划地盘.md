### 一、结论：这个框在哪

#### 世界坐标（3D 场景，单位 = 米）

```js
{ west: -96, east: -33.5, north: -33, south: 16 }   // 宽 62.5 × 高 49
```

整个场景是 `terrain.size = 192` 的方形岛，原点在岛中心，所以坐标范围是 `±96`。
`x` 向东为正、`z` 向南为正（对应地图上的「向下」）。

| 边 | 方程 | 说明 |
| --- | --- | --- |
| 北 | `z = -33`，`x ∈ [-96, -33.5]` | 贴着发卡弯底部直道的北边缘 |
| 东 | `x = -33.5`，`z ∈ [-33, 16]` | 贴着竖直道的右边缘 |
| 南 | `z = 16`，`x ∈ [-96, -33.5]` | 横穿 S 弯 |
| 西 | `x = -96`，`z ∈ [-33, 16]` | 正好是地图左边界，整条在 1.5 米深的海里 |

圆角半径 `2.25` 世界单位 —— 这个值是为了跟地图标注框对齐（`map.styl` 里 `.fenced-zone` 的 `border-radius: 12px`，在 1024px 宽的容器上折算成世界单位就是 `12 / 1024 × 192 ≈ 2.25`）。

#### 换算到各套坐标系

统一用这一个线性映射（`Map.js` 的 `worldToMap` 就是它）：

```text
归一化 u = x / 192 + 0.5
归一化 v = z / 192 + 0.5        // v 就是 CSS 的 top%，向下为正
```

| 坐标系 | 西北角 | 东南角 |
| --- | --- | --- |
| 归一化 0~1 | `(0, 0.3281)` | `(0.3255, 0.5833)` |
| 2048×2048 俯视图 | `(0, 672)` | `(667, 1195)` |
| 751×753 地图截图 | `(0, 247)` | `(244, 439)` |
| CSS 百分比 | `left 0% / top 32.81%` | `right 67.45% / bottom 41.67%` |

### 二、这些数字是怎么量出来的

1. **提取红笔轨迹**：用 `sharp` 读截图原始像素，只保留 `r > 200 && g < 45 && b < 45` 的像素。
   阈值一定要收紧，否则红白路缘石会被一起检出（第一版就糊成了 10 万噪点）。
   剩下的轨迹是个**圆角矩形**，不是椭圆：像素 `x ∈ [0, 255]`、`y ∈ [245, 444]`。
2. **校验坐标映射**：不要凭肉眼估像素。图里那 12 个白色菱形 pin 是已知世界坐标的
   （`respawns.getByName()` + `Map.js` 里每项的 `offset`），做连通域检测找出 12 个菱形中心，
   再按 `worldX = (px / W - 0.5) × 192` 反解，逐点比对误差全部 < 2 单位 → 证明映射成立，
   且那张截图正好覆盖 `±96` 全图。

#### 重烤流程

```bash
node scripts/fence-enclosure.mjs --strict --preview   # 出走向图 scripts/tmp-fence-preview.png 核对
node scripts/fence-enclosure.mjs --strict --write     # 写 sources/data/fenceEnclosure.js
```

### 四、当前摆法（strict）

```text
画线采样 102 片 → 深水跳过 29 片 → 实际摆放 73 片
其中 39 片正压在柏油路面上（strict 的预期行为，赛道在这三处被彻底封死）
```

单片栏杆长 `2.14`（碰撞体 half-extent 1.067 × 2），所以画线按 2.14 的间距切片；
`y = 地面高度 + 1.04`，地面高度取自 `static/terrain/terrain.glb` 的 129×129 顶点双线性采样

#### 两个已知取舍

1. **西边不围**：`x = -96` 整条在 1.5 米深的海里，立上去栏杆几乎全在水下（顶栏只露出水面约 5cm）。
   要围就把烘焙器里 `h < DEEP_WATER_LEVEL` 的跳过分支去掉。
2. **赛道被横穿处封死**：北边 6 片压在发卡弯直道、东边压在竖直道、南边压在 S 弯，
   栏杆是 fixed 碰撞体撞不倒。已确认 18 个 respawn 点没有一个落在区内，所以地图传送不会把自己关在里面。
